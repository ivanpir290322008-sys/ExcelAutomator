# Excel Automator

Программа на Python для автоматической обработки Excel-файлов.

## Возможности

- Объединение нескольких Excel-файлов
- Удаление дубликатов
- Сортировка по выбранному столбцу
- Проверка совместимости столбцов
- Обработка повреждённых файлов
- Сохранение результата в Excel

## Установка

Установите Python и необходимые зависимости:

```powershell
pip install -r requirements.txt
```
## Использование

1. Создайте папку `input`.
2. Поместите в неё Excel-файлы с одинаковыми названиями столбцов.
3. Запустите программу:

```powershell
python main.py
```

4. Выберите столбец и направление сортировки.
5. Результат появится в `output/result.xlsx`.

## Тестирование

python -m unittest test_main.py -v
